# 视觉规范 · 莫兰迪色板（Morandi）

> 变更：首页及全站 Token 由「暖白中性色」切换为**莫兰迪色系**（低饱和 + 灰调）。
> 影响文件：`tailwind.config.ts`、`src/app/globals.css`、`src/components/**`。
> 关联规范：`docs/spec/05-低保真结构与视觉规范.md §3.1`（本表为 05 §3.1 的现行取值）。

---

## 1. 为什么是莫兰迪

- 与 05 §1 的三条设计原则一致：**低饱和**、**留白**、**图片优先** —— 灰调底色不抢商品图。
- 首饰类目里，金银铜本身的金属色已经足够跳，界面越灰，商品越亮。
- 五色相共享同一档明度与饱和度，任意两色并置都不冲突，便于做区块分区。

## 3. 莫兰迪五色相

每个色相两档：**主色**（描边、hover、小面积点缀）+ **Weak**（块面底色）。

| 色相 | 主色 | Weak（块面） | 气质 |
|---|---|---|---|
| `mist` 雾蓝 | `#A7B2B8` | `#E2E6E8` | 冷静、现货感 |
| `sage` 豆绿 | `#A9B3A6` | `#E5E8E0` | 自然、植物系 |
| `clay` 陶粉 | `#C0A79C` | `#EEE5DF` | 手作温度 |
| `sand` 沙米 | `#CFC5B6` | `#F0EAE2` | 中性、百搭 |
| `mauve` 藕紫 | `#A7989F` | `#EAE4E7` | 复古、柔和 |

使用规则：
1. **块面只用 Weak**，主色只用于 1px 描边、hover 态、角标等小面积。
2. 一个页面最多出现 **2 个色相块面**，其余留 `bg` 底色，避免花。
3. 文字一律用 `ink`（`#35322E`）——所有 Weak 面上对比度均 ≥ 4.5:1（WCAG AA）。

## 4. Hero 渐变

```
--hero-fade: linear-gradient(155deg, #E2E5E1 0%, #E9E2D9 48%, #DAD2CA 100%);
```

雾青 → 沙米，155° 斜向。实拍主图到位后由 `<Image>` 覆盖该渐变，无需改组件。
图片未到位时，这块渐变就是正式的 Hero 视觉（占位文字照常标注 `Hero photo pending`）。

## 5. 首页当前配色落点

| 区块 | 底色 | 说明 |
|---|---|---|
| Hero | `bg-hero` 渐变 | 雾青→沙米；CTA 用 `accent` 实心 + 白字 |
| New arrivals | `bg` | 不铺底 |
| **One of a Kind** | `clayWeak` | 手工孤品 = 暖陶色（B-1.7 品类区分） |
| **Trending** | `mistWeak` | 流行款 = 冷雾蓝（B-1.7 品类区分） |
| Shop by style | `bg` | 四个入口按 mist/sage/clay/sand 循环铺 Weak 底 |
| You may like | `bg` | 不铺底 |
| Join our list | `band` | 雾色带收尾 |

> B-1.7 要求「手工款与流行款视觉呈现有可辨识差异」：除原有的 `One of a Kind` 文字角标外，
> 现在再叠加一层**色相差异**（暖 vs 冷）。颜色不是唯一通道 —— 角标仍是文字，符合无障碍要求。
