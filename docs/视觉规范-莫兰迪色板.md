# 视觉规范 · 莫兰迪色板（暖纸浅色版 · 面向 20–25 岁）

> 变更（2026-10-29 第三次调色）：由**冷石墨深色版**改为**暖纸浅色版**。
> 前两版（暖褐黑 `#232120` → 冷石墨 `#1C1E20`）连续两次被反馈"还是偏暗"，根因是把"莫兰迪"做成了
> "暗色高级感"——莫兰迪画作的底子其实是灰白、暖米、雾灰这类低饱和**亮调**，深底只是其中一种用法。
> 本版底色换成未漂白纸感米白 `#F4F1EB`，强调色换成深鼠尾草绿 `#4A6450`，靠低饱和色相与留白立气质。
> 影响文件：`tailwind.config.ts`、`src/app/globals.css`、`src/components/**`、`src/i18n/content.ts`、`public/images/**`。
> 关联规范：`docs/spec/05-低保真结构与视觉规范.md §3.1`（本表为 05 §3.1 的现行取值）。

---

## 1. 为什么是浅色莫兰迪

- 与 05 §1 的三条设计原则一致：**低饱和**、**留白**、**图片优先** —— 纸白底让银饰的冷光与珍珠的暖调各自成立，
  深底反而需要提亮金属才不糊。
- 目标用户是欧美 **20–25 岁**女性、客单价偏设计款：浅底 + 衬线大字 + 细线，更接近
  Mejuri / Missoma / Sophie Buhai 那一路的"日常可戴"，而不是橱窗式奢侈品。
- 浅底对**手作感**更友好：石膏、亚麻、未漂白纸的质感能直接露出来；深底会把这类细节吃掉。
- 五色相共享同一档饱和度，任意两色并置都不冲突，便于做区块分区。

## 3. 莫兰迪五色相（浅色版）

块面用**浅调 Weak**，描边 / hover / 点缀用**同色系深调主色**——与深色版正好反过来。

| 色相 | 主色（描边/文字） | Weak（块面） | 气质 |
|---|---|---|---|
| `mist` 雾蓝 | `#566F82` | `#E3EAEF` | 清冷、现货感 |
| `sage` 鼠尾草 | `#587152` | `#E5ECE0` | 自然、治愈 |
| `clay` 腮红陶 | `#91624E` | `#F1E3DB` | 手作温度、气色感 |
| `sand` 燕麦沙 | `#7C6942` | `#F0E8D8` | 中性、百搭 |
| `mauve` 丁香紫 | `#77628A` | `#EAE2ED` | 少女、轻盈 |

使用规则：
1. **块面只用 Weak**，主色只用于 1px 描边、hover 态、斜体大字等小面积。
2. 一个页面最多出现 **2 个色相块面**，其余留 `bg` 底色，避免花。
3. 文字一律用 `ink`（`#2C2D2A`）——所有 Weak 面上对比度均 ≥ 8:1（WCAG AA 轻松过）。
4. `clay` 主色同时是 Hero 第二行斜体大字的颜色：作为 ≥24px 大字，3.5:1 已满足 AA 大字标准。

## 7. Hero 大字排版（品牌标语）

首屏第一眼就是这句双行大字，版式固定为「眉标 → 大字 → 副标 → CTA」四层：

```
────  HANDMADE IN SMALL BATCHES                    眉标：细引线 + 全大写小字（aux/12px，字距 0.22em，375px 一行放得下）

Made by hand,                                      主标语第一行：衬线正体，text-display，ink
worn every day.                                    第二行：衬线斜体 + clay #91624E

Small-batch jewellery — one-of-a-kind pieces…      副标：body/14px，muted
[ Shop new ]                                       CTA：accent 实心 + onAccent 白字
```

- 字号 token `display`：`clamp(2.25rem, 9vw, 4.25rem)`，行高 1.04、字距 -0.015em。
  375px 屏约 36px、桌面约 68px —— 用 vw 保证窄屏不溢出（B-2.1 移动优先）。
- 只有第二行走斜体 + 陶色，其余保持 ink，避免花（衬线斜体字形已随 `Cormorant Garamond` 加载，不用合成斜体）。
- 图片上叠字靠**底部提亮层**保证可读：`h-3/5` + `from-bg → via-bg/60 → transparent`。
- **高度按视口算，不用固定宽高比**：`h-[72svh] max-h-[560px] min-h-[420px]`，桌面 `md:h-[76svh] md:max-h-[660px]`。
  原先的 `aspect-[16/9]` 在 1440 宽屏上会到 810px，加上顶栏正好把底部四层大字推出首屏（只露字头）。
- **取景**：现行主图首饰簇在画面 `62% / 48%`。移动端 `object-[62%_46%]`（竖裁保住首饰、上方留白给眉标），
  桌面 `md:object-[54%_50%]`（首饰在右、文案落在左侧窗光留白）。换图时按「首饰主体、链子末端、珍珠」三处不被切来判断焦点。
- **叠字可读性用两层提亮**：底部 `h-3/5` 竖渐变托住大字；左侧 `w-full md:w-3/5` 横渐变纸白雾（`from-bg/90`）
  保证文字栏在任何主图上都能读，同时不遮首饰一侧。眉标用 `ink/70`，**不要用投影**（浅底上黑投影会脏）。
- 动效：四层依次淡入，延迟 0 / 40 / 80 / 120ms，每层 120ms，收在 200ms 内（05 §3.4）。
- **主图缓慢推镜（Ken Burns）**：`animate-kenburns` —— 18s 单向 + alternate（整周期 36s），
  缩放 1.0 → 1.075、位移 -1.2%/-0.9%，只动 `transform`，不触发布局、不影响 LCP。
  原点 `origin-[62%_48%]` 压在首饰簇上，放大时首饰不漂移。
  `motion-reduce:animate-none` —— 系统开启「减少动态效果」时完全静止（无障碍硬要求）。
- 文案全部读 `src/i18n/content.ts` 的 `CONTENT[locale].hero`（B-2.8；0.3.0-m1b 由 `src/content/site-content.ts` 迁入并分中英两份），改字不用动组件。
- **为什么不用视频 / GIF**（2026-10-29 结论）：GIF 只有 256 色，浅色渐变同样会出色带，且体积是 MP4 的 5–10 倍；
  视频背景需处理 LCP、iOS 静音自动播放、省流量降级与「竖裁/横裁两套构图」问题，等实拍主图到位后再评估。
  当前推镜方案零资源增量，可作为将来视频加载前的过渡层。
