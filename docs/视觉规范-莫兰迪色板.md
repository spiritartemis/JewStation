# 视觉规范 · 莫兰迪色板（深色版）

> 变更：首页及全站 Token 切换为**深色莫兰迪**（低饱和 + 灰调 + 深底）。
> 影响文件：`tailwind.config.ts`、`src/app/globals.css`、`src/components/**`、`public/images/**`。
> 关联规范：`docs/spec/05-低保真结构与视觉规范.md §3.1`（本表为 05 §3.1 的现行取值）。

---

## 1. 为什么是深色莫兰迪

- 与 05 §1 的三条设计原则一致：**低饱和**、**留白**、**图片优先** —— 深灰底不抢商品图，反而让金属与宝石更亮。
- 目标用户是欧美女性、客单价偏设计款，深色底 + 留白更接近买手店 / 独立设计师品牌的调性。
- 五色相共享同一档饱和度，任意两色并置都不冲突，便于做区块分区。

## 3. 莫兰迪五色相（深色版）

块面用**暗调 Weak**，描边 / hover / 点缀用**亮调主色**。

| 色相 | 主色 | Weak（块面） | 气质 |
|---|---|---|---|
| `mist` 雾蓝 | `#A9B4BA` | `#2C3134` | 冷静、现货感 |
| `sage` 豆绿 | `#AEB8AB` | `#2E332D` | 自然、植物系 |
| `clay` 陶粉 | `#C6ADA2` | `#332C29` | 手作温度 |
| `sand` 沙米 | `#D3C9BA` | `#333029` | 中性、百搭 |
| `mauve` 藕紫 | `#B0A1A8` | `#302B2E` | 复古、柔和 |

使用规则：
1. **块面只用 Weak**，主色只用于 1px 描边、hover 态、角标等小面积。
2. 一个页面最多出现 **2 个色相块面**，其余留 `bg` 底色，避免花。
3. 文字一律用 `ink`（`#E9E4DC`）——所有 Weak 面上对比度均 ≥ 4.5:1（WCAG AA）。

## 7. Hero 大字排版（品牌标语）

首屏第一眼就是这句双行大字，版式固定为「眉标 → 大字 → 副标 → CTA」四层：

```
────  HANDMADE IN SMALL BATCHES                    眉标：细引线 + 全大写小字（aux/12px，字距 0.22em，375px 一行放得下）

Made by hand,                                      主标语第一行：衬线正体，text-display
worn every day.                                    第二行：衬线斜体 + clay #C6ADA2

Small-batch jewellery — one-of-a-kind pieces…      副标：body/14px，muted
[ Shop new ]                                       CTA：accent 实心 + onAccent 文字
```

- 字号 token `display`：`clamp(2.25rem, 9vw, 4.25rem)`，行高 1.04、字距 -0.015em。
  375px 屏约 36px、桌面约 68px —— 用 vw 保证窄屏不溢出（B-2.1 移动优先）。
- 只有第二行走斜体 + 陶粉，其余保持 ink，避免花（衬线斜体字形已随 `Cormorant Garamond` 加载，不用合成斜体）。
- 图片上叠字靠**底部压暗层**保证可读：`h-3/5` + `from-bg/95 → via-bg/55 → transparent`。
- **高度按视口算，不用固定宽高比**：`h-[72svh] max-h-[560px] min-h-[420px]`，桌面 `md:h-[76svh] md:max-h-[660px]`。
  原先的 `aspect-[16/9]` 在 1440 宽屏上会到 810px，加上顶栏正好把底部四层大字推出首屏（只露字头）。
  现在的上限保证「顶栏 + Hero ≤ 首屏」，并在下方留出下一区块的一小截作为滚动提示。
- **裁短后取景要跟着改**：`object-[38%_18%] md:object-[50%_8%]` —— 横裁变扁后焦点必须上移，否则头顶会被切；
  移动端竖裁时水平焦点偏左（人物在画面左侧 1/3）。换主图时按「人物头顶、耳饰、项链」三处不被切来判断焦点。
- **叠字可读性用两层压暗**：底部 `h-3/5` 竖渐变托住大字；左侧 `w-full md:w-3/5` 横渐变薄雾（`from-bg/70`）
  保证文字栏在任何主图上都能读，同时不遮人物一侧。眉标用 `ink/75` + 极轻投影，不用 muted（压在窗光上会消失）。
- 动效：四层依次淡入，延迟 0 / 40 / 80 / 120ms，每层 120ms，收在 200ms 内（05 §3.4）。
- 文案全部读 `src/content/site-content.ts` 的 `HOME_HERO`（B-2.8），改字不用动组件。
