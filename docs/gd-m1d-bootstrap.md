# gd-m1d-bootstrap — 可上线版本完成

> 里程碑卡 `m-1d` · 线段 `1d` · alias `launch` · 目标日期 2026-12-18 · 对外版本 V1.0  
> 排表见 `docs/gd-plan-整体版本计划.md`。

## 1. 术语

| 术语        | 含义                                                                   |
| --------- | -------------------------------------------------------------------- |
| Cookie 同意 | 首次访问的非必要 Cookie 选择界面：同意 / 拒绝 / 随时撤回偏好                                |
| 匿名访客标识    | 用户同意后分配的非个人身份 ID（Cookie 承载），用于识别回访                                   |
| 浏览行为持久化   | 服务端保存访客浏览过的商品 ID、标签与时间                                               |
| 标签推荐      | 依据近期浏览商品的标签匹配相似商品；无历史时回退新品 / 爆款                                      |
| 拒绝追踪      | 用户拒绝或撤回后，不记录用于个性化的浏览历史，也不返回个性化推荐                                     |
| 上线准备      | 域名 / SSL / 托管 / 支付收款 / 物流 / 真实商品图 / 库存 / 英文校对 / 政策审核 / 监控与告警均有负责人并完成 |

## 2. 场景

1. 新访客首次进站 → 看到 Cookie 选择 → 同意后获得匿名访客 ID → 浏览多件商品 → 离开后回访 → 首页显示按标签匹配的相似商品。
2. 访客拒绝（或撤回）→ 不记录用于个性化的浏览历史，不返回个性化推荐，但浏览、筛选、结账照常可用。
3. 首次访问（无历史）→ 推荐位显示新品 / 爆款，而不是空白。
4. 邮箱订阅：有效邮箱成功、错误邮箱被提示、可见订阅用途、可退订。

## 3. 行为（编号规则与判据）

- **B-4.1 同意优先**：任何非必要追踪（访客 ID、行为持久化、个性化推荐）**必须**在取得同意后才启动。
- **B-4.2 拒绝可用**：拒绝后其余功能（浏览、筛选、搜索、购物车、结账）不受影响。
- **B-4.3 撤回可用**：用户可随时撤回偏好，撤回后停止相关采集并说明已采集数据的处理方式。
- **B-4.4 访客 ID 是匿名的**：不含个人信息，不与支付身份直接关联；有过期 / 撤回 / 删除规则。
- **B-4.5 持久化在服务端**：访客浏览的商品 ID、标签与时间存服务端；**不以 localStorage 作为唯一持久化方案**；持久化失败时页面仍可正常浏览（降级不报错）。
- **B-4.6 推荐可解释且可回退**：按标签匹配，排除当前商品、售罄孤品与不可售商品；标签不足时回退新品 / 爆款 / 同品类。
- **B-4.7 推荐位一致**：详情页 Similar Style、首页 You may like；首次访问显示新品 / 爆款，回访且已同意才加载个性化结果。
- **B-4.8 订阅四要素**：邮箱校验、重复订阅处理、同意记录、退订方式齐备；订阅用途（新品预告 / 手工孤品预告）明示。
- **B-4.9 愿望单不阻塞首发**：访客态收藏 / 取消收藏可用且状态保存策略写明；账户同步作为后续决策，不阻塞 V1.0。
- **B-4.10 上线清单逐项有主**：域名 / SSL / 托管 / 支付 / 物流 / 商品图 / 库存 / 英文校对 / 政策审核 / 监控备份告警，每项写明负责人与完成状态。
- **B-4.11 运营验收可复现**：用代表性设备与订单流程核对首页、筛选、搜索、孤品售罄、支付、邮件、同意 / 拒绝追踪、推荐行为，留下可复核证据。

## 5. 不该发生

- 不在未取得同意前启动非必要追踪或写访客行为。
- 不把访客 ID 与支付人信息、邮箱做直接关联。
- 不用 localStorage 当作行为持久化的唯一方案。
- 不在标签不足时给出空白推荐位（必须回退）。
- 不把隐私 / Cookie 文本当作可随手改的营销文案 —— 变更须与真实数据流对照。
- 不擅自上线：支付收款、物流、真实商品图、政策审核任一未完成即不上线。

## 6. 暂不涉及

社区与评论 · 会员等级 · 向量 / 协同过滤推荐 · 复杂 AB 实验平台 · 愿望单账户同步 · 博客（属 `m-1e`）· 站内客服 IM。
