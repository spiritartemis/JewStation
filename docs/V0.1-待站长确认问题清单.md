## A 组 · 市场与品牌（定乾坤，先答）

### Q-38 目标销售国家/地区
- **背景**：决定支付商可用性、税费口径、隐私与 Cookie 适用法律、配送范围。
- **选项**：单一市场（如美国）/ 英语区（美英加澳）/ 欧盟 / 全球（先接单再筛）。
- **工程侧建议**：**起步单一市场或英语区**，变量最少、先跑通能买；全球可配送但要写明不支持的地区。
- **不答的后果**：支付商选不了、税费口径定不了、隐私政策适用法律定不了 → `m-1c` 直接卡住。
- **回填**：`08` §1 · `10` §1 · `07` §5/§6

### Q-05 主要币种
- **选项**：USD / EUR / GBP / 其他；是否同时支持多币种展示。
- **建议**：**USD 单币种**（V0.1），多币种展示留后续。
- **不答**：价格字段与结算口径无法定稿。
- **回填**：`02` §2 C 组 · `10` §1

### Q-02 是否需要多语言
- **选项**：英文单语（默认）/ 增加某语言。
- **建议**：**英文单语**；若主攻非英语市场请尽早说——文案要本地化，V0.1 的 11-06 节点可能要顺延。
- **不答**：按英文单语继续（风险：后期加语言要重做 URL 与集合页命名）。
- **回填**：`01` §4 · `10` §1

### Q-44 品牌名（英文）最终定稿
- **背景**：全站文案、SEO、邮件发件名、`/about` 都用它；现在占位是 `BRAND`。
- **建议**：一次定稿，后续不改（涉及 Logo、域名、发信域、SEO 积累）。
- **不答**：所有文案里都留 `BRAND` 占位，上线前必须全文替换。
- **回填**：`07` 全部文案 · `10` §1 · SEO 字段

### Q-39 主域名
- **背景**：站点域名 + 邮件发信域（SPF/DKIM/DMARC 验证）。
- **建议**：尽早注册，域名验证常有 24–48 小时传播期。
- **不答**：托管、SSL、邮件发信验证都推不动 → 影响 V1.0 上线。
- **回填**：`08` §3/§5 · `12` §5

### Q-01 是否需要「条款与条件（Terms）」页
- **选项**：需要 / 不需要。部分市场与支付商会要求。
- **建议**：**要**（成本极低，缺了可能被支付商或市场要求补）。
- **不答**：按不建处理（若支付商要求则临时补）。
- **回填**：`01` §2 政策页清单

### Q-03 材质与保养是否单开内容页
- **选项**：单开 `/materials-care` / 并入 FAQ。
- **建议**：V0.1 **并入 FAQ**，内容量不足以单开页。
- **回填**：`01` §2

### Q-04 品类清单是否就是耳环/项链/戒指/手链
- **选项**：这四类 / 需要增删（如胸针、发饰、套装）。
- **建议**：按**实际货盘**给清单，不要为了对齐模板硬凑。
- **回填**：`03` §2 · `01` §2 集合页

## B 组 · 交易、税费、售后（决定 m-1c 代码分支）

### Q-34 支付服务商与收款主体 🔴
- **背景**：收款主体（公司/个人 + 所在国）+ 支付商，直接决定能否开户。
- **选项**：Stripe（卡）· PayPal · 本地收单。
- **工程侧硬要求**：必须支持 webhook（成功/失败/退款）、必须有测试模式、**本站不存卡号**。
- **不答**：`1c-1 结账与支付接入` 无法开工 → V0.3（12-04）与 V1.0 连锁延期。
- **提醒**：开户与审核是**日历等待**，请 **11-06 前发起**。
- **回填**：`08` §1 · `12` §1/§2

### Q-21 配送国家/地区 🔴
- **建议**：与 Q-38 一致；先给最小可用范围。
- **不答**：结账地址表单、运费表、税费规则都写不了。
- **回填**：`07` §8 · `12` §1

### Q-22 配送时效
- **建议**：给出「处理时长 + 在途时长」两段（如 1–2 天处理 + 5–9 天在途）。
- **回填**：`07` §2 FAQ / §8

### Q-31 运费规则 🔴
- **选项**：满额包邮 / 按地区分档 / 统一价。
- **不答**：`0.3-06` 运费展示写不了。
- **回填**：`12` §3 · `07` §8

### Q-32 税费与关税口径 🔴
- **选项**：价含税（VAT/GST 内含）/ 价不含税结账加税；跨境 **DDU**（买家到付）还是 **DDP**（卖家预收）。
- **建议**：跨境默认 **DDU** 并在结账页写明，避免弃单与纠纷。
- **不答**：结账金额口径不确定 → 合规与争议风险。
- **回填**：`12` §3 · `07` §8

### Q-12 孤品退款后是否回补库存 🔴
- **选项**：A 回补（变成可售）/ B 不回补（售出即终结）。
- **工程侧建议**：**A 回补**（货在手上就能再卖）。
- **不答**：`m-1c` 的退款分支库存代码无法确定（这是代码分支，不是文案）。
- **回填**：`04` §2 事件④ · §6 状态机

### Q-13 孤品是否接受退货 🔴
- **选项**：A 不接受 / B 7 天内可退 / C 仅质量问题可退。
- **工程侧建议**：**C**（保护买家，也避免以「手工差异」为由无限退货）。
- **不答**：退换货政策与退款流程定不了。
- **回填**：`04` §7 · `07` §7 · `12` §4

### Q-28 耳饰是否因卫生原因不可退
- **背景**：许多市场对耳饰（贴身/穿孔）有卫生限制。
- **建议**：**耳饰非质量问题不退**，并在商品页与政策页写明。
- **回填**：`07` §7

### Q-23 退货窗口 / Q-29 退款处理时长
- **建议**：窗口 14 天（自签收起）；退款在验收后 3–5 个工作日内完成。
- **回填**：`07` §7 · `12` §1

### Q-33 物流商 / Q-30 发货地 / Q-35 是否接受「运费写死」
- **背景**：V0.1 不接实时报价 API，运费按规则表写死展示。
- **建议**：接受写死（省一期工作量）；物流商与发货地请给实际值。
- **回填**：`07` §8 · `08` §5

### Q-36 邮件服务商（交易邮件 + 订阅）🔴
- **建议**：同一家（如 Resend / Postmark 类），域名验证一次搞定。
- **不答**：`1c-4 交易邮件模板`、`1.0-06 订阅` 无法配置。
- **回填**：`08` §1 · `13` §2

### Q-47 客服邮箱域名
- **建议**：`support@<主域名>`，须与发信域一致。
- **回填**：`07` §1 · `12` §1
