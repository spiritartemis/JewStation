# JewStation 整体版本计划（gd-core 板 `jew`）

> 依据：《版本计划与任务清单.md》《建站任务拆分与版本规划.md》《独立站需求方案-流行饰品与手工饰品.md》。
> 本文件是**排表**（先后顺序 + 归属 + 优先级 + 目标日期）；每条开发线的**什么算做对**写在同目录 `gd-m1*-bootstrap.md`（规格）。
> 计划日期以 2026-10-27（周二）为起算日；工期口径沿用原文：任务工期 = 投入工日，不含等待站长补资料 / 服务商审核 / 法律审核的日历等待。

## 1. 计划口径（两轴）

| 轴 | 载体 | 归属规则 |
|---|---|---|
| **开发轴** | 里程碑卡 `m-<序号><代际字母>` = 一条开发线 | 需求挂开发线（`R-jew-<线段>-<线内序号>`），任务挂需求（`T-jew-<线段>-<序号>-NN`） |
| **发布轴** | 对外版本 `V0.1 … V1.1` | 版本号归发版流程（`gd release`），**不写进里程碑 id / alias**；版本 ↔ 需求是「版本 → 需求成员」多对多关系 |

**本次映射（一条版本 = 一条开发线，一一对应，便于排期与验收）**

| 版本 | 开发线卡 | 线段 | 定位（一句话） | alias | 起止 | 目标日期 | 工期 |

## 3. 关键路径与依赖

```
m-1a 商品数据模型(1a-1) ─┬─→ m-1b 商品列表/详情(1b-2,1b-4) ─→ m-1c 购物车/结账(1c-0,1c-1)
                        └─→ m-1b 首批导入(1b-8) ←── 站长商品资料(1a-7)
m-1a 孤品状态规则(1a-2) ─────→ m-1c 库存与订单状态(1c-2) ←── 交易售后规则(1a-8)
m-1a 技术选型(1a-5) ─────────→ m-1c 支付/邮件接入(1c-1,1c-4) ←── 服务账户(1c-6)
m-1b 页面与政策(1b-5) ─────────→ m-1d 同意管理(1d-0) → 匿名访客(1d-1) → 持久化(1d-2) → 推荐(1d-3,1d-4)
m-1c 交易闭环 ─────────────────→ m-1d 上线准备与验收(1d-7,1d-8) ←── 业务审核(1d-9)
上线后真实数据 ────────────────→ m-1e 推荐调优(1e-2) / 转化优化(1e-3)
```

**硬阻塞（不做就得延期）**

1. `1a-1 商品数据模型` → `1b-8 首批导入` → `1b-2/1b-4 列表与详情`：没有字段口径，商品页写不了。
2. `1a-5 技术选型` → `1c-1 支付接入`：支付/邮件服务商开户与审核是**日历等待**，须在 11-06 前启动。
3. `1a-8 交易售后规则` → `1c-2 库存规则` → `1c-6 账户配置`：取消/退款是否回补库存必须先定。
4. `1b-5 政策页文案` → `1d-0 同意管理`：同意条文案与真实数据流（访客 ID / 分析 / 邮件 / 支付 / 物流）必须一致。
5. 孤品不超卖**必须服务端保证**（`1c-2`），前端隐藏按钮不算。

## 6. 发布轴（版本号）安排

- 版本号只在发版流程产生；本板（core）当前**没有 `gd release` 写面**，因此版本 ↔ 需求的成员关系先记在里程碑 `note` 里（每条线注明其目标版本），等完整 CLI 可用时一次性灌入发版账。
- 建议对外版本序列：`0.1`（预览站：V0.2 完工即可上线不收款版本）→ `0.2`（交易闭环）→ `1.0`（正式上线）→ `1.1`（运营迭代）。
- 铁律：结版（`ver reach`）与里程碑达成（`milestone reach`）**都须用户点名确认**，不由 AI 代行。

## 7. 风险登记

| 风险 | 影响 | 应对 |
|---|---|---|
| 真实商品资料 / 实拍图延迟 | `1b-8` 首批导入、`1b-9` 正式素材无法开工 | 11-06 前锁定首批 10 款；AI 图仅作设计稿 |

## 8. 落板操作清单（获批后执行）

```bash
# ① 5 条开发线（里程碑 = 开发线，id 自动 m-1a..m-1e）
./tools/gd milestone add "基础需求确认与基础资源制作" --target 2026-11-06 --alias foundation --series a --note "对外版本 V0.1"
./tools/gd milestone add "可浏览各个页面及其商店"     --target 2026-11-20 --alias storefront --series b --note "对外版本 V0.2"
./tools/gd milestone add "交易模块上线并完成闭环"     --target 2026-12-04 --alias checkout   --series c --note "对外版本 V0.3"
./tools/gd milestone add "可上线版本完成"             --target 2026-12-18 --alias launch     --series d --note "对外版本 V1.0"
./tools/gd milestone add "运营优化"                   --target 2026-12-31 --alias growth     --series e --note "对外版本 V1.1（滚动）"

# ② 需求（挂线）——每条需求建完立刻挂里程碑
./tools/gd req new "<需求标题>" --line 1a --summary "<一句话>"

# ③ 任务（挂需求）
./tools/gd task add R-jew-1a-0 --task "local:确认站点地图与导航"

# ④ 名册扩容（站长执行体）——board.yaml executors 增加 owner
# ⑤ 收工备份
./tools/gd core snap --backup
```

> 落板顺序纪律：**需求必须先挂里程碑再拆任务**（需求一旦全任务完成即进终态，事后补挂会被达成判据挡住）。
