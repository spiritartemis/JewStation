## 1. 语言路由

| 语言 | 对外 URL | 说明 |
|---|---|---|
| 英文（默认） | `/`、`/shop`、`/products/xxx` | 不带前缀，地址栏干净 |
| 中文 | `/zh`、`/zh/shop`、`/zh/products/xxx` | slug 仍是英文词（Q-02：中文页 slug 用英文词） |

- 实现：页面在 `src/app/[locale]/`，无前缀请求由 `src/middleware.ts` **内部重写**到 `/en/...`，
  不是 301 跳转，所以不会多一跳、也不会出现 `/en/shop` 这种多余地址。
- 每页都输出三条 hreflang（`en` / `zh-CN` / `x-default`），canonical 指向**该语言自己的**地址。
- sitemap 中英各一条 URL 并互相声明 hreflang；`/search`、`/cart` 两种语言都不进索引。

## 2. 文案放在哪

| 内容 | 文件 | 谁写 | 谁审 |
|---|---|---|---|
| 界面词条（按钮、筛选、状态、页脚） | `src/i18n/messages.ts` | 工程侧 | 站长抽审 |
| 长文（About / FAQ / 隐私 / Cookie / 退换 / 配送 / 条款） | `src/i18n/content.ts` | 工程侧出英文底稿 + 中文初稿 | **站长逐段审中文** |
| 标签名（品类/风格/材质/类型） | `src/data/tags.json` 的 `label` / `labelZh` | 工程侧 | 站长抽审 |
| 商品文案 | `src/data/products.sample.json` 的 `i18n.zh` | 运营（首批由站长给） | 站长 |

**中文稿状态**：全部为「机翻初稿 + 品牌口吻校对」，**未经站长审核**，不得当作终稿上线。
审的时候只改中文，不动英文；`zh` 少一个键 `tsc` 会直接报错，所以不会出现中文页漏词。

## 3. 双币种

- 商品数据只存**美元价**（`price` + `currency: "USD"`），人民币是**展示换算**，不改数据。
- 汇率取**中国银行**外汇牌价「美元现汇卖出价」，单位是每 100 美元，代码里除以 100。
- **每天 0 点（北京时间）刷新**：缓存 TTL 取「距下一个北京时间 0 点的秒数」，
  所以 0 点后第一次请求就是新价，而不是按 24 小时滚动。
- 兜底：抓不到中行页面时用固定汇率 7.1，并在页脚的汇率行明确标注「暂不可用」，
  不会拿旧数字冒充实时价。
- 主动刷新（部署侧定时任务，00:00 Asia/Shanghai 打一次）：

  ```bash
  curl -X POST "https://<域名>/api/fx/refresh?token=$FX_REFRESH_TOKEN"
  ```

  需要配置环境变量 `FX_REFRESH_TOKEN`；没配时该端点返回 503（不留无鉴权重算入口）。
- 币种切换记在 cookie `mm_currency`；默认值按语言走（英文站美元、中文站人民币）。
- **结算币种以结账页为准**：页面上的另一个币种一律标注为约值，不当成成交价。

## 4. 六个品类与可选规格

- 品类：Earrings / Necklaces / Rings / Bracelets / **Bag Charms** / **Sets**。
  桌面导航因从 4 个增到 6 个，收进 `Shop` 下拉（原生 `<details>`，无 JS 也能开）。
- 可选规格（Q-06）：手链「开口 / 死圈」用 `options` 表达，**同一款、一个价、一份库存**；
  戒指码数仍用 `sizeOptions`（固定码数），两者不混用。详情页有选择器，选择结果会显示在规格行下方。

## 7. 验收怎么看

1. 打开 `/` 与 `/zh`，确认两种语言的首页、导航、页脚都对得上。
2. 顶栏右切 `USD / CNY`：中文页默认人民币，切回美元后刷新页面仍然记得。
3. `/zh/policies/shipping` 与 `/policies/returns`：确认义乌发货、两段时效、满额包邮、DDP、14 天退、耳饰不退这些口径写对了。
4. `/products/vintage-link-bracelet`：规格行能选「开口 / 死圈」。
5. `/collections/bag-charms`、`/collections/sets`：两个新品类各有 1 件样例商品。
6. `/sitemap.xml`：中英成对出现。
