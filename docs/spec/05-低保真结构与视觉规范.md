## 1. 设计原则（先定调子）

1. **图片优先**：商品图是主角，UI 是背景。任何装饰元素不得压过商品图。
2. **低饱和**：色彩克制，用大面积中性色 + 少量品牌强调色；不用高饱和撞色。
3. **留白**：间距比内容更重要，移动端尤其靠留白做呼吸感，不靠分割线。
4. **移动优先**：所有布局先定 375px，再向上适配；不做桌面专属复杂布局。
5. **克制动效**：动效只用于「反馈与过渡」，时长 ≤ 200ms；不做弹跳、不做自动轮播轰炸。

### 2.4 购物车 / 结账 / 订单确认（V0.1 只定结构）

- **购物车**：条目行（图 + 名 + 单价 + 数量步进 + 小计）→ 底部结算条（合计 + Checkout）
- **结账**：单列表单（邮箱 → 配送地址 → 配送方式 → 支付），步骤指示 3 步，不强制注册
- **订单确认**：成功头图 + 订单号（可复制）+ 商品摘要 + 配送信息 + 客服邮箱

## 3. 视觉基础（Token）

### 3.1 色彩（低饱和 · 莫兰迪灰调）

### 3.2 字体

| 用途 | 建议 | 说明 |
|---|---|---|
| 标题 / 品牌 | 衬线（如 `Cormorant Garamond` 类） | 有手作与质感；**待 Q-15 确认** |
| 正文 / UI | 无衬线（如 `Inter` / 系统字体） | 小字号清晰度优先 |
| 字号（移动端） | H1 20/28 · H2 16/20 · 正文 14/22 · 辅助 12/18 | 行高 ≥ 1.5 |
| 字重 | 只用 400 / 500 / 600 三档 | 不用 700+，避免厚重感 |

### 3.3 间距与圆角（8pt 栅格）

| Token | 值 |
|---|---|
| `--sp-1` … `--sp-6` | 4 / 8 / 12 / 16 / 24 / 32 |
| 页面左右安全边距 | 16px（移动端） |
| 区块间距 | 32px |
| 圆角 | 图片 4px · 卡片 8px · 按钮 6px（不做大圆角） |

### 3.4 卡片 / 按钮 / 动效

| 元素 | 规范 |
|---|---|
| 商品卡片 | 图 4:5 占满卡宽；图下 12px 间距后是名称（最多 2 行截断）→ 价格；无边框，靠留白分隔 |
| 主按钮 | 全宽 48px、实心强调色、白字、6px 圆角 |
| 次按钮 | 描边 1px、透明底、文字用主色 |
| 禁用态 | 前景 40% 透明 + 不可点击（Sold 用灰底 + 划线） |
| 动效 | 只允许：淡入 120ms、位移 ≤ 8px、按钮按压缩放 0.98；**禁止**自动轮播弹窗、弹跳、闪烁 |

## 4. 手工款 vs 流行款的视觉差异（B-1.7 硬要求）

| 位置 | 手工 / 孤品 `one_of_a_kind` | 流行 / 可补货 `restockable` |
|---|---|---|
| 卡片角标 | **「One of a Kind」** 实心角标（左上） | 无角标；库存 ≤ 3 时显示「Only N left」 |
| 卡片边框 | 1px 暖调描边（`--c-accent-weak`） | 无描边 |
| 详情页标题上 | 角标 + 「Only one made」说明行 | 显示库存状态 |
| 详情页说明 | `handmadeVariation` + `oneOfAKindNote` 常显 | 无 |
| 售罄表现 | **Sold**（永久、记录保留） | Out of stock（可补货） |
| 图片调性 | 允许更近的手作细节特写 | 标准白底/场景图 |

> 差异必须**不依赖颜色 alone**（无障碍）：角标文字 + 说明行同时存在。

## 5. 无障碍与性能基线（与 0.2-07/0.2-08 衔接）

- 对比度：正文 ≥ 4.5:1，大字 ≥ 3:1
- 可点击区域 ≥ 44×44px
- 所有图片必须有 `alt`（商品图的 alt 见 `06` 模板）
- 焦点可见（键盘导航有描边）
- 首屏只加载首图，其余懒加载；图片必须有宽高，防 CLS
