## 2. 数据与商品管理方式（重点权衡）

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| A. 纯 JSON/Markdown 入仓 | 零成本、可版本管理 | 库存是动态数据，**孤品不超卖需要事务**，文件不适合 | ❌ |
| B. 无头 CMS（Sanity/Contentful） | 编辑体验好、图片托管现成 | 月费、字段模型受限于 CMS、库存事务仍要自建 | ⚠️ 过度 |
| **C. Postgres + 自建轻量 Admin** | 库存/订单可事务、推荐与浏览记录同一库、成本可控 | 要写后台界面（约 1–2 天） | ✅ **建议** |

**理由**：孤品「不超卖」是硬要求，必须有服务端事务与唯一约束；浏览行为持久化（`1.0-03`）与推荐（`1.0-04`）也要落库。三者共用同一个库最省事。

## 3. 环境划分

| 环境 | 用途 | 数据 | 域名 |
|---|---|---|---|
| `local` | 开发 | 本地库 + 种子数据 | `localhost:3000` |
| `preview` | 每个 PR 自动预览（Vercel Preview） | 预发库（副本/脱敏） | `*.vercel.app` |
| `production` | 正式 | 生产库 | 主域名（待定 Q-39） |

规则：**生产库与预发库物理隔离**；预发不得连生产库；生产数据不得下载到本地。

## 4. 密钥管理（B-1.9 硬要求）

| 项 | 存放 | 禁止 |
|---|---|---|
| 支付密钥（Stripe secret / webhook secret） | 托管平台环境变量（加密） | ❌ 入仓 / ❌ 写进文档 / ❌ 前端 |
| 数据库 URL | 环境变量 | 同上 |
| 邮件服务 API Key | 环境变量 | 同上 |
| 对象存储密钥 | 环境变量 / 平台 IAM 角色 | 同上 |

落地约定：
1. 仓内只提交 `.env.example`（**只有键名，没有值**）。
2. `.gitignore` 已含 `.env*` —— 提交前再核一次。
3. 密钥轮换：支付与邮件密钥每 6 个月或人员变动时轮换【待站长确认 Q-40】。
4. 站长提供密钥走**安全渠道**（平台环境变量面板直接填 / 密码管理器），不要用聊天窗口或邮件明文发。

## 5. 第三方服务的集成约束（给站长的选型依据）

| 服务 | 工程侧约束 | 影响选型的因素 |
|---|---|---|
| 支付 | 需支持：多币种（当前单币种）、webhook（成功/失败/退款）、测试模式；需能处理重复回调 | 目标市场是否支持、收款主体所在地、费率、结算周期 |
| 物流 | 只需回传：可配送国家、时效、运费；**不接实时报价 API**（V0.1） | 发货地、目标市场、是否含关税 |
| 邮件 | 需支持：域名发信验证（SPF/DKIM/DMARC）、模板或 API 发送、退信处理 | 域名所有权、发信量、是否支持订阅分组 |
| 托管 | 需支持：Node 运行时、环境变量、自动预览、日志 | 成本、地区、是否需要自定义域名 SSL（免费即可） |

## 6. 成本口径（V0.1 阶段，实际以站长账户为准）

| 项 | 预估 | 说明 |
|---|---|---|
| 托管（Vercel Hobby/Pro） | 0 – 20 USD/月 | 上线前流量小，Hobby 可先用；商用需 Pro |
| 数据库（Neon/Supabase） | 0 – 25 USD/月 | 免费档起步，有连接数限制 |
| 域名 | ~10–15 USD/年 | 待定 Q-39 |
| 支付 | 按交易费率 | 无月费（Stripe 类） |
| 邮件 | 0 – 20 USD/月 | 交易邮件量小 |
| 对象存储/CDN | 托管平台内含或少量 | 图片量不大 |

> 以上为量级参考，**不做报价承诺**；实际以站长账户与服务商定价为准。

## 7. 风险与回退

| 风险 | 影响 | 回退方案 |
|---|---|---|
| 支付商不支持目标市场/主体 | `1c-1` 无法开工 | 备选 PayPal / 本地收单；若都不行，先上「不收款预览站」（V0.2 完工即可上线，见排表 §6） |
| 免费档数据库连接数不足 | 并发下单失败 | 升级档位或换托管 Postgres |
| 域名与发信验证耗时 | 交易邮件延迟 | 先用平台默认发信域，正式域名验证后切换 |
| 站长账号未开 | 环境无法搭建 | **须在 11-06 前发起开户**（排表 §4 硬阻塞） |
