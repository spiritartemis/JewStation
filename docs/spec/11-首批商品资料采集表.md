## 4. 完整率自检（B-1.10 · 8 项必填）

每款逐项打勾，8 项全勾才算完整：

| # | 必填项 | 说明 |
|---|---|---|
| 1 | ☐ 售价 `price` | 真实售价，含币种 |
| 2 | ☐ 库存 `stock` | 孤品=1；可补货填实数 |
| 3 | ☐ 商品类型 `productType` | 孤品 / 可补货 |
| 4 | ☐ 材质 `materials` | 含纯度与是否含镍 |
| 5 | ☐ 尺寸 `dimensions` | 实测 mm |
| 6 | ☐ 重量 `weight` | 实测 g |
| 7 | ☐ 照片 `images` ≥3 张 | 实拍，每张有 alt |
| 8 | ☐ 标签 `tags` | 品类 + 风格 + 材质 |
