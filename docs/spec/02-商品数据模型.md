# 02 · 商品数据模型（V0.1 · 0.1-02）

> 里程碑 `m-1a` / 需求 `R-jew-1a-1` / 任务 `T-jew-1a-1-01`
> 判据：字段至少包含英文标题、slug、短文案、详情、价格与币种、图片及 alt、材质、尺寸、重量、过敏提示、保养、库存、商品类型、风格/材质/品类标签、SEO 字段。
> **B-1.2 一次定稿**：字段表含类型、必填性、示例值与来源（实物/运营）；定稿后任何增删必须回写 §7 变更记录。
> **B-1.4 双商品类型共用一套模型**：孤品与可补货款字段完全一致，差异只由 `商品类型 + 库存` 表达，不为孤品另立字段组。
> 状态：**草案 · 待站长确认**

---

## 1. 模型总览

一张 `Product` 表覆盖全部商品（孤品 + 可补货款），字段分 7 组：

| 组 | 作用 | 组 |
|---|---|---|
| A 标识 | 商品在系统中的身份与地址 | A |
| B 文案 | 面向买家与 SEO 的文字 | B |
| C 价格与库存 | 交易相关 | C |
| D 物理属性 | 材质/尺寸/重量/工艺事实 | D |
| E 合规与保养 | 过敏提示、保养、手工差异 | E |
| F 媒体 | 图片与 alt | F |
| G 分类与标签 | 风格/材质/品类/商品类型 | G |

## 2. 字段表（B-1.2 定稿表）

图例：**必填 ✔** / 条件必填 ◐ / 选填 ○ · 来源：**实物**（须实测/实拍）/ **运营**（可撰写）

### A · 标识

| 字段 | 类型 | 必填 | 示例值 | 来源 | 说明 |
|---|---|---|---|---|---|
| `id` | string | ✔ | `prd_01HXYZ…` | 系统 | 内部主键，不对外暴露 |
| `sku` | string | ✔ | `JS-EAR-0012` | 运营 | 库存单位编码；孤品与可补货款同规则 |
| `slug` | string | ✔ | `silver-wave-hoops` | 运营 | URL 片段；**发布后不可改**（改需 301） |
| `createdAt` / `updatedAt` | datetime | ✔ | `2026-11-02T09:00Z` | 系统 | 审计用 |

### B · 文案（站点语言默认英文）

| 字段 | 类型 | 必填 | 示例值 | 来源 | 说明 |
|---|---|---|---|---|---|
| `title` | string(≤60) | ✔ | `Silver Wave Hoops` | 运营 | 英文商品名，列表与详情页主标题 |
| `shortCopy` | string(≤120) | ✔ | `Hand-formed sterling silver hoops with a soft wave.*` | 运营 | 氛围短文案，卡片与推荐位用 |
| `description` | markdown | ✔ | 段落 + 要点 | 运营 | 详情正文（工艺、灵感、佩戴场景） |
| `highlights` | string[] | ◐ | [`Hand-formed`, `Nickel-free`] | 运营 | 卖点要点，详情页要点区 |
| `seoTitle` | string(≤60) | ✔ | `Silver Wave Hoops \| BRAND` | 运营 | 缺省回退 `title` |
| `seoDescription` | string(≤155) | ✔ | `Handmade sterling silver wave hoops…` | 运营 | 缺省回退 `shortCopy` 截断 |
| `ogImage` | image ref | ○ | 主图 | 系统 | 分享预览图，缺省用主图 |

### C · 价格与库存

| 字段 | 类型 | 必填 | 示例值 | 来源 | 说明 |
|---|---|---|---|---|---|
| `price` | decimal | ✔ | `48.00` | 运营 | 数值，不含货币符号 |
| `currency` | enum ISO4217 | ✔ | `USD` | 运营 | **全站单币种**（V0.1）；多币种留待后续 |
| `compareAtPrice` | decimal | ○ | `60.00` | 运营 | 划线价；无则不显示 |
| `productType` | enum | ✔ | `one_of_a_kind` \| `restockable` | 运营 | **B-1.4**：唯一的商品类型字段 |
| `stock` | int ≥ 0 | ✔ | 孤品恒 `1`；可补货款 `0–999` | 实物 | **B-1.5**：孤品库存恒为 1 |
| `availability` | enum（派生） | ✔ | `in_stock` \| `sold_out` | 系统 | 由 `stock` 派生，不手填 |
| `status` | enum | ✔ | `draft` \| `active` \| `archived` | 运营 | 上下架；孤品售出后不删除，转 `sold_out` 保留 |

### D · 物理属性（实物事实，不得估算）

| 字段 | 类型 | 必填 | 示例值 | 来源 | 说明 |
|---|---|---|---|---|---|
| `materials` | string[] | ✔ | [`Sterling silver 925`, `Freshwater pearl`] | 实物 | 主材与辅材；用标签字典的标准名 |
| `metalPurity` | string | ◐ | `925` | 实物 | 金属类必填（如 925 / 14k / 18k） |
| `plating` | string | ◐ | `18k gold vermeil` | 实物 | 有电镀/包金时必填 |
| `dimensions` | object | ✔ | `{ "length": "32mm", "width": "4mm", "unit": "mm" }` | 实物 | 长/宽/直径等，单位固定 mm |
| `weight` | object | ✔ | `{ "value": 3.2, "unit": "g" }` | 实物 | 单位固定 g，需实测 |
| `closureType` | string | ◐ | `Latch back` | 实物 | 耳饰/项链/手链必填 |
| `sizeOptions` | string[] | ◐ | [`16`, `17`, `18`] | 实物 | 戒指/手链有码数时必填 |

### E · 合规与保养

| 字段 | 类型 | 必填 | 示例值 | 来源 | 说明 |
|---|---|---|---|---|---|
| `allergyNotice` | string | ✔ | `Contains nickel-free brass; not suitable for nickel allergy.` | 运营 + 实物 | **金属过敏提示**，详情页与政策页一致 |
| `careInstructions` | string | ✔ | `Avoid water and perfume; store in the pouch.` | 运营 | 保养说明 |
| `handmadeVariation` | string | ◐ | `Each pair is hand-formed; slight differences in wave depth are expected.` | 运营 | **手工/天然差异说明**；孤品与手工款必填 |
| `oneOfAKindNote` | string | ◐ | `Only one made. Not reproducible after sold.` | 运营 | 孤品必填 |

### F · 媒体

| 字段 | 类型 | 必填 | 示例值 | 来源 | 说明 |
|---|---|---|---|---|---|
| `images[]` | image[] | ✔（≥3 张） | — | 实物 | 主图 + 细节 + 佩戴图；**V0.1 首批须为实拍** |
| `images[].url` | string | ✔ | `/img/products/JS-EAR-0012-01.jpg` | 系统 | 相对路径 |
| `images[].alt` | string | ✔ | `Silver wave hoop earrings on a model's ear` | 运营 | **每张都要 alt**（无障碍 + SEO） |
| `images[].width/height` | int | ✔ | `1200 / 1500` | 系统 | 防布局跳动（CLS） |
| `images[].order` | int | ✔ | `0` | 运营 | 排序，0 为主图 |
| `images[].isPrimary` | bool | ✔ | `true` | 运营 | 主图标记，唯一 |

### G · 分类与标签（与 `03-标签字典` 同源）

| 字段 | 类型 | 必填 | 示例值 | 来源 | 说明 |
|---|---|---|---|---|---|
| `category` | enum（单值） | ✔ | `earrings` \| `necklaces` \| `rings` \| `bracelets` | 运营 | 品类，决定主分类与集合页 |
| `tags.style[]` | enum[] | ✔（≥1） | [`minimal`] | 运营 | 风格标签 |
| `tags.material[]` | enum[] | ✔（≥1） | [`sterling-silver`] | 运营 | 材质标签，与 `materials` 对齐 |
| `tags.occasion[]` | enum[] | ○ | [`everyday`] | 运营 | 场景标签（选填维度，V0.1 可留空） |
| `tags.collection[]` | enum[] | ○ | [`wave-series`] | 运营 | 系列/主题（选填） |

## 3. 孤品 vs 可补货款（B-1.4 / B-1.5）

| 维度 | 孤品 `one_of_a_kind` | 可补货款 `restockable` |
|---|---|---|
| 字段 | **完全相同**（不为孤品另立字段组） | 同 |
| `stock` | 恒为 `1` | `0–999` |
| 售罄表现 | `Sold` · 不可加购 · **不删除记录** | `Out of stock` · 可到货通知（V1.1） |
| 必填额外文案 | `oneOfAKindNote` + `handmadeVariation` | 无 |
| 并发 | 服务端保证不超卖（m-1c） | 服务端校验 |

> 任何 `stock > 1` 的记录**不得**标记为孤品（B-1.5 硬约束）。

---

## 4. 校验规则（m-1b 建表时直接实现）

1. `productType=one_of_a_kind` ⇒ `stock` 必须为 `1`，否则拒绝写入。
2. `stock=0` ⇒ `availability=sold_out`，前端不可加购。
3. `title` ≤ 60、`seoTitle` ≤ 60、`seoDescription` ≤ 155，超出提示截断。
4. `images` 至少 3 张且每张有 `alt`；无 alt 视为不完整。
5. `dimensions.unit` 固定 `mm`、`weight.unit` 固定 `g`。
6. `currency` 全站统一（V0.1 单币种）。
7. 标签值必须存在于标签字典（外键约束，防同物异名）。

---

## 5. 完整率定义（B-1.10 · 首批 10 款）

**必填无缺项** = 下列 8 项齐备：`price`、`stock`、`productType`、`materials`、`dimensions`、`weight`、`images`（≥3 实拍有 alt）、`tags`（style + material + category）。
缺项必须**逐条列出待补**（见 `11-首批商品资料采集表.md`），不得留空蒙混。
