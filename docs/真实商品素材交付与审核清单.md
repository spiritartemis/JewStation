## 3. 交付方式

1. 图片按 `public/img/products/<SKU>-01.jpg` … 命名打包（命名规则见 `商品录入流程.md` §3）。
2. 文字信息填 `docs/spec/11-首批商品资料采集表.md` 的单款明细表，或直接给表格/表格文件。
3. 工程侧录入后跑 `node scripts/validate-products.mjs`，把不通过项回给站长补齐。

## 5. 采集模板（0.2-10 新增）

`docs/首批商品采集模板.csv` 已按数据模型 `02` 的字段顺序建好 10 行空表，字段口径与
`scripts/validate-products.mjs` 完全一致：

| CSV 列 | 对应数据模型字段 | 填写要求 |
|---|---|---|
| `sku` | `sku` | 唯一；建议 `JS-<品类>-<四位序号>` |
| `slug` | `slug` | 小写连字符，不含空格；与标题一致但可缩写 |
| `productType` | `productType` | 只能填 `one_of_a_kind` 或 `restockable` |
| `stock` | `stock` | 孤品恒 `1`；可补货填实际数量 |
| `category` / `style` / `materials` | 同名 | **只能填 `src/data/tags.json` 里的 slug**，多个用 `;` 分隔 |
| `dimensions_*_mm` | `dimensions` | 单位固定 mm，只填实测值，没有的留空 |
| `weight_g` | `weight` | 单位固定 g，必填 |
| `allergyNotice` / `careInstructions` | 同名 | 必填；按实际成分写，禁 `hypoallergenic` 等无依据宣称 |
| `handmadeVariation` | 同名 | 孤品与手工款必填 |
| `image1`–`image4` | `images[]` | 填文件名（如 `JS-EAR-0001-01.jpg`），实拍图放 `public/img/products/` |

填完把 CSV 与图片一起给工程侧，按 `商品录入流程.md` 的步骤导入并跑校验。
