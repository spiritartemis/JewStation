# gd-m1b-bootstrap — 可浏览各个页面及其商店

> 里程碑卡 `m-1b` · 线段 `1b` · alias `storefront` · 目标日期 2026-11-20 · 对外版本 V0.2  
> 排表见 `docs/gd-plan-整体版本计划.md`。

## 1. 术语

| 术语   | 含义                                         |
| ---- | ------------------------------------------ |
| 商店   | 商品发现体验：首页 → 列表/筛选 → 详情 → 政策页的全链路（**不含支付**） |
| 筛选维度 | 风格 / 品类 / 材质 / 价格 / 手工属性（孤品 or 可补货）        |
| 售罄态  | 孤品成交后展示为 sold out，且不可加入购物车                 |
| 视觉规范 | 沿用 `m-1a` 的低保真结构与视觉规范（移动优先、低饱和、留白、图片优先）    |
| 首批导入 | 用可重复的录入流程导入首批真实商品                          |

## 2. 场景

1. 访客在手机端进首页 → 点风格入口 → 组合材质/品类/价格筛选 → 进详情页，信息与图片完整。
2. 访客用商品名或标签搜索，无结果时给出明确提示与「清空搜索」。
3. 访客打开品牌页 / FAQ / 隐私与 Cookie 政策页，页内链接正确，文案可维护。
4. 站长按流程录入首批商品（可重复操作），并确认价格、库存、材质声明与实物一致。

## 3. 行为（编号规则与判据）

- **B-2.1 移动优先**：主流手机宽度下无横向溢出；桌面端为顺延而非另做一套布局。
- **B-2.2 首页区块固定**：Hero → 新品 → 手工孤品 → 流行款 → 风格入口 → 初访默认推荐位 → 安静的订阅入口（订阅入口在 `m-1d` 实现前留位不外链）。
- **B-2.3 筛选可组合**：风格/品类/材质/价格/手工属性可叠加；每个筛选值可直达 URL（可分享、可回退）。
- **B-2.4 卡片信息完整**：商品类型标记（Handmade / Trending）、价格、主图、售罄状态在列表与筛选结果中可见。
- **B-2.5 搜索覆盖名与标签**：命中商品英文标题与标签；空结果、清空搜索、无结果提示三者齐备。
- **B-2.6 详情页信息义务**：图片、材质、尺寸、重量、保养、过敏提示、库存状态、手工说明、不可复刻提示；相似风格与搭配推荐区留位（`m-1d` 填充）。
- **B-2.7 孤品售罄可见**：孤品成交后立即显示售罄且不可加入购物车 —— 本线只做**展示与按钮禁用**，防超卖由 `m-1c` 服务端保证。
- **B-2.8 文案可维护**：品牌 / FAQ / 政策文本从内容源读取，不硬编码在组件里；上线前由业务方复核。
- **B-2.9 SEO 基线**：每页独立 meta title / description；商品图有准确 alt；规范 URL 与分享预览齐备；页面可被抓取。
- **B-2.10 性能基线**：响应式图片；非首屏图延迟加载；无重动画；首屏商品图清晰且不过度拖慢加载。
- **B-2.11 录入流程可重复**：同一套流程可再次录入新商品，字段完整率达标，图片与库存与实物一致。

## 4. 待定（谁能否决）

| 待定项                  | 现状           | 谁能否决 / 定夺                    |
| -------------------- | ------------ | ---------------------------- |
| 真实商品实拍图（可正式销售）       | 未提供          | 站长（`owner`）；未到位则 `1b-9` 无法验收 |
| 最终英文商品信息与价格          | 未提供          | 站长                           |
| 商品管理方式（后台 / 表单 / 脚本） | 依 `m-1a` 选型定 | 工程侧决定，需站长给账号                 |
| 搜索实现（站内 / 外部服务）      | 未定           | 工程侧；外部服务需站长付费与授权             |
| 首页 Hero 文案与 banner   | 未定           | 站长出素材，工程侧排版                  |

## 5. 不该发生

- 不在本线接支付、购物车下单、结账 —— 属 `m-1c`。
- 不在本线做推荐算法与访客追踪 —— 属 `m-1d`；本线只留推荐位与初访默认位。
- 不做评论区、会员等级、密集促销弹窗。
- 不用 AI 生成图冒充正式商品图上线（设计稿可用，正式商品须实拍）。
- 不把 SEO 做成堆关键词：每页 description 需描述该页真实内容。

## 6. 暂不涉及

支付与订单 · 邮件（交易邮件 / 订阅）· Cookie 同意与匿名访客 · 个性化推荐 · 愿望单 · 博客 · 账户体系 · 桌面专属布局。
